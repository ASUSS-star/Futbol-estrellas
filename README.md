# Top Jugadores — Proyecto Final React

App React (Vite) que consume un JSON propio alojado en GitHub.

## Ejecutar
```
npm install
npm run dev
```
## Configurar la API
Edita `src/config.js` y pon tu usuario/repo de GitHub en la URL raw de `public/data/jugadores.json`.

## Despliegue (Netlify)
Build command: `npm run build` · Publish directory: `dist`
(`public/_redirects` ya maneja las rutas de React Router.)
